Things I've built

Job Application Tracker

A web app where each person keeps track of the jobs they have applied for. You sign up, log in, and add, edit or delete your applications from a Streamlit dashboard. The Flask API behind it checks a JWT on every protected request, so people only see their own data.

Python · Flask · SQLite · JWT · bcrypt · Streamlit

  • Passwords are stored as bcrypt hashes.
  • A token_required decorator guards every route except signup and login.
  • All four operations (create, read, update, delete) work and are tested end to end.
  • The code is public on GitHub with a README.

How I got here

For my first two semesters I had no laptop, so I learned Python on my phone with Pydroid 3 and Google Colab. I still type examples out by hand instead of pasting them, because it makes me understand every line.

After that came a six-week plan covering Pandas, NumPy, Matplotlib, Seaborn and scikit-learn, practised on the Titanic dataset. Then I moved to backends. I learn fastest by building, and a backend gives me something I can run and break.

The Job Application Tracker is where it started to come together: passwords, tokens, protected routes and a database, all working in one app. Next I want to build something real time.
